# Навигатор поступления

Веб-прототипы для учеников NIS Туркестан. Интерфейс на двух языках (RU / ҚАЗ), без сервера и без сборки.

| Файл | Что это |
|---|---|
| `index.html` | Навигатор: дедлайны 11 программ, план шагов, калькулятор ЕНТ, эссе и рекомендации, новости, экспорт в календарь, отчёт куратору |
| `quest.html` | Квест профессий: 8 мини-миссий → профиль склонностей. Результат подхватывает навигатор |
| `curator.html` | Кабинет куратора: сводная таблица класса из кодов учеников, сортировка, фильтр по классу, CSV |
| `data.js` | Программы, сроки, данные ЕНТ, связь квеста с программами (тексты RU + KK) |
| `i18n.js` | Словарь интерфейса RU / ҚАЗ и общие функции дат |
| `feeds.js` | Список RSS-лент новостей |
| `news.js`, `pages.js` | Данные, которые пишут скрипты ниже. Руками не править |
| `update-news.mjs` | Скачивает новости → `news.js` |
| `check-pages.mjs` | Проверяет официальные страницы программ → `pages.js` |
| `motion.css`, `motion.js` | Общие анимации всех страниц |
| `sw.js`, `manifest.webmanifest`, `icon*` | PWA: установка на телефон и офлайн-режим |

Прогресс ученика хранится в localStorage его браузера.

## Что обновляется само

- **Дедлайны.** Дедлайн, прошедший больше 30 дней назад, переносится на ту же дату следующего года с пометкой «ожид.». Отсчёт пересчитывается при смене дня.
- **Новости** (поступление, учёба, «Эврика»: наука и открытия): `update-news.mjs` каждые 30 минут. Страница перечитывает `news.js` сама. Если файл старше 35 минут, она пробует загрузить ленты через публичные CORS-прокси.
- **Сайты приёма:** `check-pages.mjs` раз в день сравнивает строки с датами на официальных страницах. Если они изменились, в плане и на карточке программы 14 дней висит предупреждение «проверьте даты».

### Вариант 1. GitHub Pages (рекомендуется)

Сайт открывается по ссылке с любого телефона. Обновления запускает `.github/workflows/update.yml`.

1. Создать репозиторий и залить файлы.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Actions → «Обновление новостей и проверка сайтов» → Run workflow (первый запуск вручную).

Расписание GitHub Actions может опаздывать на 5–15 минут, это нормально.

### Вариант 2. Только на этом компьютере (Windows, нужен Node.js)

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-autoupdate.ps1
```

Скрипт создаёт задачи в Планировщике: новости каждые 30 минут, проверка сайтов в 9:00. Вручную: `node update-news.mjs`, `node check-pages.mjs`.

## Калькулятор ЕНТ

Минимумы по предметам: история Казахстана 5/20, математическая и читательская грамотность 3/10, профильные 5/50. Пороги конкурса: 50 (обычные вузы), 65 (национальные), 70 (медицина), 75 (право, педагогика).
Проходные баллы по направлениям взяты из разбора официального списка грантов на 2026–2027 учебный год: [NotaBene](https://notabene.courses/lm/ent-grants/) по данным МНВО РК. В разборе опубликованы только 16 направлений. Чтобы добавить новые, впишите их в `ENT_GROUPS` в `data.js`. Каждый год после публикации списков (до 10 августа) цифры нужно обновить.

## Кабинет куратора

Сервер не нужен. Ученик вписывает имя и класс в блоке «Отчёт куратору» и нажимает «Скопировать код» (строка `NAV1.…`) или «Скачать файл», потом отправляет куратору. Куратор вставляет коды в `curator.html`. Повторный код того же ученика заменяет старый. Данные хранятся только в браузере куратора.

## Дизайн и motion

Правила анимаций лежат в скилле `.claude/skills/motion/SKILL.md` (`/motion` в Claude Code).

Локальный запуск: Live Server в VS Code → Open with Live Server. Офлайн-режим и установка приложения работают только по http(s), через `file://` они недоступны.

## Дизайн-обновление

- Шкала дедлайнов на 12 месяцев над списком (точки кликабельны, цвет = программа).
- Кольцо баллов ЕНТ с отметками порогов 50/65/70/75.
- Значки и цвета программ (`PROG_META` в `data.js`), поиск и фильтры по региону и финансированию.
- На телефоне вкладки уходят в нижнее меню с иконками.
- Пустые состояния с иллюстрацией, онбординг из 3 шагов при первом входе (`nav.onb`).
- Размер текста A−/A+ на всех страницах (`nav.zoom`).
- Достижения (`nav.ach`, `nav.flags`), конфетти при 100% плана.
- «Распечатать план»: при печати остаются только план и документы, в светлой теме.
