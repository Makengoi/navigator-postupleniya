# Motion для «Навигатора поступления»

Анимация здесь служит пониманию: показывает, откуда появился элемент, что изменилось и что идёт загрузка. Если анимация ничего не объясняет, её не добавляем.

## Токены (класть в `:root` рядом с цветами)

```css
--dur-1:120ms;  /* ховер, нажатие, смена цвета */
--dur-2:220ms;  /* появление мелких элементов, переключатели */
--dur-3:420ms;  /* вход панели, карточки, полосы прогресса */
--ease-out:cubic-bezier(.2,.8,.2,1);      /* по умолчанию для входа */
--ease-in-out:cubic-bezier(.65,0,.35,1);  /* перемещения индикаторов */
--ease-spring:cubic-bezier(.34,1.56,.64,1); /* только мелкие «щелчки»: галочки, бейджи */
--stagger:40ms;
```

Длительность никогда не превышает 500 мс, кроме бесконечных индикаторов загрузки.

## Правила

1. Анимируем только `transform` и `opacity` (плюс `background-position` у скелетона). Никаких `width/height/top/left`, кроме полос прогресса, где ширина и есть смысл.
2. **Вход панели/вкладки**: `opacity 0→1` + `translateY(8px→0)`, `--dur-3`, `--ease-out`. Класс `.enter` вешаем на панель при показе и снимаем на `animationend`, иначе повторный `render()` через `innerHTML` перезапустит анимацию.
3. **Каскад (stagger)**: дети списка получают `style="--i:N"` и `animation-delay:calc(var(--i)*var(--stagger))`. Ограничиваем `--i` значением 10, чтобы длинный список не «тянулся».
4. **Ховер карточки**: `translateY(-2px)` + мягкая тень, `--dur-1`. На тач-устройствах не нужен: оборачиваем в `@media (hover:hover)`.
5. **Нажатие кнопки**: `:active{transform:scale(.97)}`.
6. **Индикатор вкладок**: один абсолютный `<span>` под `nav`, двигается через `transform:translateX()` и `width`, `--dur-2 --ease-in-out`. Позицию пересчитываем при `resize`.
7. **Числа** (дни до дедлайна, баллы): count-up от прошлого значения к новому за 600 мс через `requestAnimationFrame` с easeOutCubic, `font-variant-numeric:tabular-nums`, чтобы цифры не прыгали.
8. **Загрузка**: скелетон-карточки с бегущим градиентом (`background-size:200%`, 1.2 с, linear, infinite) и вращение иконки обновления. Никаких спиннеров на весь экран.
9. **Подтверждение действия**: галочка/бейдж — короткий `scale(.6→1)` с `--ease-spring`, `--dur-2`.
10. **Срочность**: пульсирует только одна точка у ближайшего дедлайна ≤ 7 дней. Не больше одного пульсирующего элемента на экран.

## Доступность — обязательно

```css
@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{animation-duration:.01ms!important;animation-iteration-count:1!important;transition-duration:.01ms!important;scroll-behavior:auto!important}
}
```

В JS перед count-up и другими rAF-анимациями проверяем `matchMedia("(prefers-reduced-motion: reduce)").matches` и сразу ставим конечное значение.

## Чек-лист перед сдачей

- [ ] Все длительности и кривые берутся из токенов, а не вписаны числами.
- [ ] Повторный `render()` не перезапускает анимации входа.
- [ ] С `prefers-reduced-motion: reduce` интерфейс полностью работает и ничего не двигается.
- [ ] Нет горизонтального скролла от `translateX` на ширине 360 px.
- [ ] Темная и светлая темы: тени и скелетоны видны в обеих (используем токены `--line`, `--surface`).

## Общие файлы `motion.css` + `motion.js`

Подключены на всех страницах. Что в них уже есть, не дублируйте:

- **Смена темы**: новая тема расходится кругом от кнопки (View Transitions, код в `i18n.js`). Без поддержки API тема меняется сразу.
- **Появление при прокрутке**: `.wrap .box`, `.prog`, `.news`, `.g`. Прячутся только блоки ниже экрана. После появления классы `.rv/.in` снимаются, чтобы вернулись ховеры.
- **Волна от нажатия**: `.btn`, `.toggle`, `.chip`, `.refresh`, `.install`, `.opt`.
- **Тень под вкладками** появляется, когда шапка ушла за верх экрана.
- **Направление вкладок**: `data-dir="next|prev"` на панели, она въезжает справа или слева.
- **Блик на полосе плана**, когда всё отмечено (`.bar i.full`).
- **Плавающие круги в шапке**: единственное бесконечное декоративное движение. Медленное (24–30 с), при reduced motion выключено.
